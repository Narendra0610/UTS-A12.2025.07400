# Pengenalan Kopi | Coffee Guide

Landing page tentang dunia kopi: jenis kopi, cara menyeduh, kopi dari Nusantara, serta sebuah form data diri. Dibuat sebagai tugas mata kuliah **Pemrograman Web Dasar**.

## Fitur

- **Jenis kopi**: kartu Arabika, Robusta, dan Liberika, lengkap dengan pemilih selera yang merekomendasikan jenis kopi.
- **Metode seduh**: V60, Espresso, dan Kopi Tubruk, dengan langkah-langkah yang bisa dibuka dan ditutup.
- **Kalkulator takaran**: hitung kebutuhan air (V60, rasio 1:15) atau hasil ekstraksi (Espresso, rasio 1:2) dari jumlah bubuk kopi.
- **Kopi Nusantara**: daftar daerah penghasil kopi di Indonesia.
- **Form data diri**: nama, alamat, kota, dan hobi, dengan validasi Bootstrap dan ringkasan data setelah dikirim.
- **Mode gelap**: mengikuti pengaturan perangkat dan pilihannya diingat.
- **Interaksi**: navbar yang menandai bagian aktif, progress bar scroll, tombol kembali ke atas, animasi muncul saat scroll, dan efek hover.
- **Responsive**: nyaman dibuka dari HP, tablet, maupun desktop.

## Teknologi

- HTML5
- CSS3 (variabel CSS, grid, flexbox, media query)
- JavaScript (tanpa library tambahan)
- [Bootstrap 5.3.3](https://getbootstrap.com/) lewat CDN
- Google Fonts: Archivo dan Source Serif 4
